# Earth Board Game — 온라인 교실 멀티플레이어

6학년 영어 Lesson 12 `We Should Save the World` 보드게임의 웹 버전입니다.

## 폴더 구조

```
earth-board-game/
├─ package.json
├─ server.js
├─ README.md
└─ public/
   ├─ index.html     (학생 화면)
   └─ teacher.html   (교사 현황판)
```

## 실행

1. Node.js 18 이상 설치
2. 이 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 접속

같은 와이파이의 태블릿은 교사 컴퓨터의 로컬 IP를 사용하여 `http://교사IP:3000`으로 접속할 수 있습니다. Windows 방화벽에서 포트 3000 허용이 필요할 수 있습니다.

## 인터넷 공개 배포

Render.com 등 Node.js 호스팅 서비스에 이 폴더를 GitHub 저장소로 업로드하고, Web Service를 생성합니다.
- Build command: `npm install`
- Start command: `npm start`
- 서비스가 제공하는 HTTPS URL을 학생들에게 공유
- 교사는 '방 만들기', 학생들은 같은 URL에서 '방 입장하기' 선택

## 게임 구성

- 한 방 최대 8명. 30명 수업은 4~6개 모둠방 권장
- 교사는 진행 화면, 학생은 각자 자기 차례에 문제 풀이
- W 21문항, S 21문항, 보석 읽기 21문장
- 실시간 위치/점수 동기화, 정답 자동 채점
- 보석 읽기 평가는 학생의 완료 버튼으로 처리하며 자동 음성인식은 포함되지 않음
- PPT 원본의 말판 순서에 맞춘 32칸 디지털 보드

## 유의사항

- 현재 방 데이터는 서버 메모리에 저장되며 재시작하면 사라집니다.
- 학생이 새로고침하거나 와이파이가 잠깐 끊겨도 같은 탭에서는 자동으로 다시 입장합니다(같은 이름·점수·위치 유지). 연결이 끊긴 학생의 차례는 자동으로 건너뜁니다.
- 서버가 재시작되면 모든 방과 점수가 사라집니다.
- 단일 서버 인스턴스 배포를 권장합니다. 다중 인스턴스에서는 Redis 어댑터 및 공용 저장소가 필요합니다.
- 교육용 프로토타입입니다. 학생은 실명 대신 별명을 사용하도록 권장합니다.
- 원본 자료 중 선택형 문항의 표현/환경 관련 판단은 수업 활동에 맞춰 유지하되 명백한 영문 철자 오류는 수정했습니다.

## 교사 통합 대시보드 (v2)

- 교사는 `https://배포주소/teacher.html` 에 접속합니다.
- 4~8개 모둠방을 한 번에 생성합니다. 각 모둠마다 별도 5자리 입장 코드가 표시됩니다.
- 학생은 `https://배포주소/` 에 접속해 자신의 모둠 코드를 입력합니다.
- 교사는 대시보드에서 **모둠별 입장 인원, 학생별 점수/위치, 합계·평균 점수, 완주 인원, 모둠 순위**를 실시간으로 확인합니다.
- 모둠별 시작 또는 `입장한 모둠 전체 시작` 버튼을 사용할 수 있습니다.
- 같은 브라우저 탭에서 새로고침하면 교사 대시보드는 `sessionStorage`의 임시 인증 정보로 다시 접속합니다. 학생도 같은 탭에서 새로고침하면 자동으로 다시 입장합니다.
- 교사용 접속 링크/인증 정보는 학생에게 공유하지 마세요. 서버 재시작 시 방과 점수가 초기화됩니다.
- 교사 화면은 별도 URL `/teacher.html`, 학생 화면은 `/` 입니다.

**운영 팁:** 30명 수업에서는 5모둠 × 6명 또는 6모둠 × 5명을 추천합니다. 서로 다른 모둠의 합계 점수는 참여 인원에 따라 차이가 생기므로 평균 점수를 함께 보세요. 보석 카드 읽기는 자동 음성 인식이 아니라 학생이 완료 버튼을 누르는 방식입니다.
