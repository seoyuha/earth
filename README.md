# Earth Board Game — 온라인 교실 멀티플레이어

6학년 영어 Lesson 12 `We Should Save the World` 보드게임의 웹 버전입니다.

## 폴더 구조

```
earth-board-game/
├─ package.json
├─ server.js
├─ README.md
└─ public/
   ├─ index.html     (학생 화면)
   ├─ teacher.html   (교사 관리 화면)
   └─ assets/        (게임 그래픽 62개, webp 약 1MB)
```

## 실행

1. Node.js 18 이상 설치
2. 이 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 접속

같은 와이파이의 태블릿은 교사 컴퓨터의 로컬 IP를 사용하여 `http://교사IP:3000`으로 접속할 수 있습니다. Windows 방화벽에서 포트 3000 허용이 필요할 수 있습니다.

## 인터넷 공개 배포

Render.com 등 Node.js 호스팅 서비스에 이 폴더를 GitHub 저장소로 업로드하고, Web Service를 생성합니다.
- Build command: `npm install`
- Start command: `npm start`
- 서비스가 제공하는 HTTPS URL을 학생들에게 공유
- 교사는 '방 만들기', 학생들은 같은 URL에서 '방 입장하기' 선택

## 게임 구성

- 한 방 최대 8명. 30명 수업은 4~6개 모둠방 권장
- 교사는 진행 화면, 학생은 각자 자기 차례에 문제 풀이
- 기본 28문제(단어 쓰기 10 · 문장 고르기 10 · 보석 읽기 8), 칸에 도착할 때마다 무작위 출제(한 판 안에서는 겹치지 않음)
- 실시간 위치/점수 동기화, 정답 자동 채점
- 보석 읽기 평가는 학생의 완료 버튼으로 처리하며 자동 음성인식은 포함되지 않음
- 섬 지도 그림 보드판 28칸 (칸에는 번호만 표시, 28번 트로피가 도착점)

## 유의사항

- 현재 방 데이터는 서버 메모리에 저장되며 재시작하면 사라집니다.
- 학생이 새로고침하거나 와이파이가 잠깐 끊겨도 같은 탭에서는 자동으로 다시 입장합니다(같은 이름·점수·위치 유지). 연결이 끊긴 학생의 차례는 자동으로 건너뜁니다.
- 서버가 재시작되면 모든 방과 점수가 사라집니다.
- 단일 서버 인스턴스 배포를 권장합니다. 다중 인스턴스에서는 Redis 어댑터 및 공용 저장소가 필요합니다.
- 교육용 프로토타입입니다. 학생은 실명 대신 별명을 사용하도록 권장합니다.
- 원본 자료 중 선택형 문항의 표현/환경 관련 판단은 수업 활동에 맞춰 유지하되 명백한 영문 철자 오류는 수정했습니다.

## 교사 통합 대시보드 (v2)

- 교사는 `https://배포주소/teacher.html` 에 접속합니다.
- 4~8개 모둠방을 한 번에 생성합니다. 각 모둠마다 별도 5자리 입장 코드가 표시됩니다.
- 학생은 `https://배포주소/` 에 접속해 자신의 모둠 코드를 입력합니다.
- 교사는 대시보드에서 **모둠별 입장 인원, 학생별 점수/위치, 합계·평균 점수, 완주 인원, 모둠 순위**를 실시간으로 확인합니다.
- 모둠별 시작 또는 `입장한 모둠 전체 시작` 버튼을 사용할 수 있습니다.
- 같은 브라우저 탭에서 새로고침하면 교사 대시보드는 `sessionStorage`의 임시 인증 정보로 다시 접속합니다. 학생도 같은 탭에서 새로고침하면 자동으로 다시 입장합니다.
- 교사용 접속 링크/인증 정보는 학생에게 공유하지 마세요. 서버 재시작 시 방과 점수가 초기화됩니다.
- 교사 화면은 별도 URL `/teacher.html`, 학생 화면은 `/` 입니다.

**운영 팁:** 30명 수업에서는 5모둠 × 6명 또는 6모둠 × 5명을 추천합니다. 서로 다른 모둠의 합계 점수는 참여 인원에 따라 차이가 생기므로 평균 점수를 함께 보세요. 보석 카드 읽기는 자동 음성 인식이 아니라 학생이 완료 버튼을 누르는 방식입니다.


## v3 — 그래픽 교체 및 화면 재구성

그려 둔 'We Should Save the World' 그래픽 시트에서 이미지를 잘라 내 학생·교사 화면을 다시 구성했습니다.

**학생 화면 (`/`)**
- 첫 화면: 타이틀 일러스트 + 8종 동물 캐릭터(눈표범·레서판다·바다거북·오랑우탄·우파루파·천산갑·사막여우·흰수염고래) 선택 → 이름 → 모둠 코드 → [입장하기]
- 같은 모둠에서 이미 고른 캐릭터를 고르면 남은 캐릭터로 자동 변경되고 안내가 뜹니다.
- 말판: 섬 지도 그림 보드판. 그림 속 번호(16·18·23 누락, 순서 뒤섞임)를 지우고 길을 따라 1~28로 다시 새김. 칸이 27개라 10~14번 사이 길 위에 돌 칸 1개(13번)를 추가함. 28번 트로피가 도착점.
- 문제: 사용 중인 28문제 중 하나가 무작위로 나오고, 한 판 안에서는 28문제가 다 나올 때까지 겹치지 않음.
- 캐릭터 말이 한 칸씩 이동하고, 주사위 굴림 애니메이션이 모둠 전원에게 보입니다.
- 문제 창: W/S/보석 카드 그림, A·B 선택지, [정답 확인] 버튼. 결과는 '정답!/틀렸어요!/보석 획득!/완주!' 효과로 표시(이전의 alert 창 제거).
- 친구 차례에는 친구가 푸는 문제가 함께 보이고, 친구 결과는 아래 알림으로 뜹니다.
- 게임 종료 시 왕관 순위 창.

**교사 관리 화면 (`/teacher.html`)** — 시안과 같은 4개 탭
- 방 관리: 방 목록(인원·상태·접속 코드·상세·시작/종료), 방 추가, 전체 시작, 선택된 방 정보(학생별 캐릭터·위치·진행 막대·점수·접속 상태), 방 이름 변경, 방 삭제, 학생 퇴장, 다시 하기
- 문제 관리: W / S / 보석 문제 보기·추가·수정·삭제, 사용 여부 켜고 끄기, 기본 문제로 되돌리기
  - 수정한 문제는 교사 브라우저에 저장되어 다음 수업에도 유지되고, 진행 중인 수업에는 바로 적용됩니다.
- 진행 상황: 접속 학생·전체 점수·정답 수·완주 학생, 모둠별 평균 진행도·정답 수·보석 획득, 모둠 순위(평균), 학생 TOP 10
- 설정: 학생 접속 주소 복사, 새 학급 모둠방 만들기

**참고**
- 그래픽 원본 시트의 주사위 눈은 오류(6 없음)가 있어 1~6 주사위 면은 같은 스타일로 새로 그렸습니다.
- 학생 화면의 '교사: 방 만들기' 버튼은 없애고 교사 관리 화면 링크로 바꿨습니다(서버의 단독 방 기능은 호환용으로 남아 있음).
- 글꼴은 나눔스퀘어라운드 ExtraBold(OFL 무료 글꼴)를 `public/fonts/`에 함께 넣어 두어 외부 글꼴 서버 없이도 똑같이 보입니다. 제목·버튼에는 시안처럼 진한 외곽선을 넣었습니다.
